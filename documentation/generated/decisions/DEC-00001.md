# DEC-00001

```text
DECISION TRACE DEC-00001

Objective:
Decide how to organize system data so that nothing gets mixed together.

Context:
The system must preserve history, allow analysis, produce reusable knowledge and expose an operational brain.

Constraints:
- Must survive between sessions
- Must be inspectable by a human
- Must not require a server to run

Alternatives considered:
A. One single database holding everything  (rejected: Mixes interpretation with raw history; impossible to audit.)
B. One flat folder of markdown files  (rejected: Not queryable, no relations, no graph.)
C. Five separated levels: raw / processed / knowledge / project / control  ← SELECTED

Decision:
Five-level separation (raw, processed, knowledge, project, control).

Justification:
Raw stays immutable and auditable; processed can be regenerated; knowledge becomes reusable; control lets a new session avoid re-reading the universe.

Consequence:
The processed level can always be rebuilt from raw. Losing an index is never losing history.

Status: APPROVED
```
